Predictive Pulse – AI-Powered Predictive Maintenance

Predictive Pulse is an AI-powered predictive maintenance system that uses machine learning to identify potential equipment failures before they occur. It analyzes operational sensor data to help support proactive maintenance decisions and reduce unexpected downtime.

Problem Statement

Traditional maintenance approaches often rely on fixed schedules or respond only after equipment failure. These approaches can result in unnecessary maintenance, unexpected breakdowns, and operational downtime.

Proposed Solution

Predictive Pulse uses an Artificial Neural Network (ANN) to analyze machine operating conditions and predict potential failures. The system processes sensor-related features and generates predictions to support early identification of equipment failure risks.

Key Features

  • Machine failure prediction using an ANN model.
  • Data preprocessing and feature scaling.
  • Analysis of machine operating conditions.
  • Binary classification of failure and non-failure cases.
  • Model evaluation using multiple performance metrics.
  • Deployment of the predictive maintenance application.

Dataset

The project uses the AI4I 2020 Predictive Maintenance Dataset from the UCI Machine Learning Repository. The dataset contains machine operational information and failure-related records.

Machine Learning Model

An Artificial Neural Network (ANN) is trained to learn patterns in machine operating data and classify whether a potential failure is likely to occur.

Model: Artificial Neural Network (ANN)

Task: Binary Classification

Dataset: AI4I 2020 Predictive Maintenance

Preprocessing: Feature selection and StandardScaler

Decision Threshold: 0.5

Model Performance

The model was evaluated on the test dataset using classification metrics and ROC-AUC.

Accuracy: 93.10%

Precision: 31.38%

Recall: 86.76%

F1-Score: 46.09%

ROC-AUC: 97.16%

Technology Stack

Programming Language: Python

Machine Learning: TensorFlow / Keras

Data Processing: Pandas, NumPy

Preprocessing: Scikit-learn

Visualization: Matplotlib

Project Outcome

The trained ANN achieved a ROC-AUC score of 97.16% and a recall of 86.76% on the test set, demonstrating its ability to identify a substantial proportion of failure cases. The project explores how machine learning can support data-driven predictive maintenance.

Adaptive SDN-Based Framework

An adaptive Software-Defined Networking (SDN)-based framework for intelligent load balancing and task scheduling in cloud environments. The framework integrates the Ryu SDN controller, Mininet network emulator, and African Vulture Routing Optimization (AVRO) algorithm to support intelligent task allocation across virtual machines.

Problem Statement

Traditional task scheduling approaches may not adequately respond to changing resource availability and network conditions in cloud environments. Uneven task distribution can lead to resource imbalance, increased response time, and reduced overall performance.

Proposed Solution

The proposed framework combines SDN-based network monitoring with AVRO-based optimization to make informed task scheduling decisions. It evaluates virtual machine conditions and selects suitable resources for task allocation.

Key Features

  • SDN-based network monitoring using the Ryu controller.
  • Network simulation and testing using Mininet.
  • Intelligent task scheduling using AVRO.
  • Adaptive load balancing across virtual machines.
  • Fast-path mechanism using a fitness-gap threshold of 0.3.
  • Performance comparison with Round Robin and Random Forest-based scheduling.

AVRO Optimization

African Vulture Routing Optimization (AVRO) is used to evaluate virtual machine suitability based on CPU usage, memory usage, queue length, and network delay.

Population Size: 10

Maximum Iterations: 100

Fast-Path Threshold: 0.3

Observed Convergence: Approximately 10–15 iterations

Best Observed Fitness: Approximately 0.747

Technology Stack

Programming Language: Python

SDN Controller: Ryu

Network Emulator: Mininet

Optimization Algorithm: AVRO

Visualization: Matplotlib

Performance Evaluation

The framework was evaluated using Uniform, Bursty, and Gravity workloads. Its performance was analyzed using the following Quality of Service (QoS) metrics:

  • Makespan
  • Throughput
  • Average Response Time
  • Network Delay
  • Resource Utilization

Research Contribution

The project integrates metaheuristic-based task scheduling with SDN-enabled network management to support adaptive resource allocation and intelligent load balancing in cloud environments.

Research Publication

Research paper accepted at IEEE COSMIC.
