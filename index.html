StudySpark AI

AI-powered personalized learning platform with intelligent tutoring and document-based learning.

Technologies:
React TypeScript FastAPI Gemini AI LangGraph PostgreSQL Tailwind CSS

Project Description

StudySpark AI is a full-stack, AI-powered learning platform designed to deliver personalized courses, adaptive tutoring, and interactive learning experiences. It leverages multi-agent AI systems to dynamically generate learning paths, analyze knowledge gaps, and enable document-based learning through intelligent PDF interaction.

Problem Statement

Traditional learning platforms are static and fail to adapt to individual learner needs. StudySpark AI addresses this by personalizing content, pace, and difficulty using AI-driven learning intelligence.

Core Features

  • AI-generated personalized learning paths from natural language input
  • Multi-agent AI tutoring with adaptive difficulty
  • PDF-based learning: question answering, summarization, and quiz generation
  • Learning progress, engagement, and gap tracking
  • Gamification elements to improve motivation and consistency

Architecture & Tech Stack

Backend:

  • FastAPI for scalable API design
  • Google Gemini API for AI content generation
  • LangGraph for multi-agent AI workflows
  • PostgreSQL (Supabase) with SQLAlchemy ORM
  • OAuth 2.0 (Google) authentication
  • PDF ingestion and processing pipeline (PyPDF2, pdfplumber)

Frontend:

  • React with TypeScript
  • Tailwind CSS with shadcn/ui
  • Zustand and React Query for state management
  • Framer Motion for animations
  • Recharts for analytics and progress visualization

My Role

Full-stack developer (Team Project - College Mini Project)

  • Built responsive and animated frontend using React, TypeScript, Tailwind CSS, and Framer Motion
  • Designed learning dashboards and AI chat interfaces
  • Integrated frontend with backend APIs using React Query and Zustand
  • Implemented AI workflows using Gemini API and LangGraph
  • Developed PDF processing and question-answering logic
  • Contributed to backend API design and data modeling

Challenges & Learnings

  • Faced API quota limits while generating and processing multiple PDFs daily using Gemini
  • Optimized prompt design to reduce token usage
  • Implemented caching and controlled generation frequency
  • Designed graceful degradation when AI limits were reached

Udaan

Udaan is an AI-powered web platform designed to support students with diverse learning needs. It offers intelligent summaries, translations, dyslexia-friendly reading modes, audio narration, flashcards, quizzes, and detailed dashboards for students and teachers.

Technologies:
Python Flask SQLite Gemini AI OCR TTS Accessibility AI-Powered Learning

Project Description

Udaan is a comprehensive AI-powered learning platform designed specifically to support students with diverse learning needs. The platform leverages Google's Gemini AI to provide intelligent content summarization, translation services, and accessibility features to make learning more inclusive and effective.

Key Features

  • AI-powered content summarization for complex topics
  • Real-time translation for multilingual learners
  • Dyslexia-friendly reading modes with customizable fonts and spacing
  • Audio narration for auditory learners
  • Interactive flashcards and quizzes for enhanced retention
  • Comprehensive dashboards for both students and teachers
  • OCR technology for extracting text from images
  • Text-to-speech capabilities for improved accessibility

Technical Implementation

The platform is built using Python Flask as the backend framework with SQLite for data persistence. The AI features are implemented using Google's Gemini API for natural language processing, OCR for text extraction, and TTS for audio generation. The frontend provides an accessible interface with various customization options to accommodate different learning needs.
