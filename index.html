Technologies:
React TypeScript FastAPI Gemini AI LangGraph PostgreSQL Tailwind CSS

Problem

Students face significant challenges with information overload, lack of personalization, and accessibility issues when studying from large documents or learning materials. Traditional learning platforms are static and fail to adapt to individual learner needs, resulting in reduced engagement and inefficient learning outcomes.

Solution

StudySpark AI is a full-stack, AI-powered learning platform that processes educational documents to provide summaries, translations, quizzes, and accessibility-focused learning tools for students and educators. The platform leverages multi-agent AI systems to dynamically generate personalized learning paths and enable document-based learning through intelligent PDF interaction.

My Contribution

  • Designed and implemented responsive, user-centric frontend interfaces for the StudySpark AI platform
  • Integrated AI-driven features such as summaries, quizzes, and translations into the user interface
  • Built role-based dashboards for students and teachers with a focus on usability and accessibility

Tech Stack

Frontend: HTML, CSS, JavaScript, React

Backend: FastAPI, Flask / Node.js

AI: Google Gemini API, NLP-based text processing (summarization, translation, quiz generation)

Database: PostgreSQL, MongoDB / SQL

Impact

The platform improves learning efficiency and accessibility by enabling personalized, inclusive study experiences for learners with diverse needs. By providing adaptive content delivery and accessibility features, StudySpark AI helps bridge the gap between traditional learning methods and modern AI-powered educational tools, resulting in improved engagement and learning outcomes.

The platform improves learning accessibility and inclusivity by enabling students with different abilities and language preferences to engage with educational content more effectively. By providing adaptive content delivery and accessibility features, Udaan bridges the gap between traditional learning methods and modern AI-powered educational tools, resulting in improved engagement and learning outcomes for diverse student populations.
